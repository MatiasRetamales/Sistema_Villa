Sistema de Control de Acceso - Villa El Ensueño

Descripción

Sistema web desarrollado como proyecto de título para apoyar la gestión y el control de acceso de residentes, visitas y personal externo en una comunidad residencial.

El proyecto busca digitalizar y mejorar el registro de ingresos y salidas, facilitando la consulta y administración de la información.

Tecnologías utilizadas

Python

Django

SQLite

HTML

CSS

JavaScript

Módulos del sistema

Residentes: gestión de la información de los residentes.

Accesos: registro y consulta de ingresos y salidas.

Autorizaciones: gestión de autorizaciones de acceso.

Los módulos y funcionalidades se encuentran sujetos al avance de desarrollo del proyecto.

Instalación y ejecución

Clonar o descargar el repositorio.

Crear un entorno virtual de Python.

Instalar las dependencias desde requirements.txt.

Configurar la base de datos.

Ejecutar las migraciones de Django cuando corresponda.

Iniciar el servidor local con python manage.py runserver.

Estado del proyecto

Proyecto en desarrollo, presentado como avance académico para revisión.
